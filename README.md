Closures in My Code
Closures are used in this project to retain state and create private scope. In memoize(), the returned function forms a closure over the cache variable, preserving function results between calls. In counter(), the returned object methods (inc, dec, value) share access to the encapsulated count variable. This prevents direct external mutation and guarantees reliable state encapsulation.
